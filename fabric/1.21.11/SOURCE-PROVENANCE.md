# Origem das fontes

O código desta variante foi reconstruído com Vineflower 1.12.0 a partir do [port publicado para Fabric 1.21.11](https://www.curseforge.com/minecraft/mc-mods/immersive-portal/files/9215662). O JAR de entrada tem SHA-256 `00e7c80ad344648394d2d832061873bf1c20b18f571339ce9ec9e2e08c38a5f7`. A licença e os créditos foram preservados. Os ajustes locais vieram da base NeoForge 1.21.1 fornecida.

O projeto compila as fontes em `src/main/java` com os mapeamentos oficiais e gera um JAR intermediário para o Fabric Loader.
